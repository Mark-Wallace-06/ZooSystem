# Zoo Management System

## Overview
A console-based Zoo Management System developed in Java as part of my university coursework. The project models zoo animals and their behaviours using object-oriented programming principles.

## Features
- Animal management and representation
- Inheritance to model different animal types
- Interfaces for behaviours such as swimming and flying
- Object-oriented class design
- Console-based interaction and output

## Technologies
- Java
- Object-Oriented Programming (OOP)

## Concepts Demonstrated
- Classes and objects
- Inheritance and polymorphism
- Interfaces
- Encapsulation
- Method implementation and overriding

## Project Structure
The project is organised into Java classes representing animals, their shared characteristics and specialised behaviours.

## How to Run
1. Clone or download this repository.
2. Open the project in a Java IDE or configure a Java development environment.
3. Compile the Java source files.
4. Run the class containing the `main()` method to launch the program.

## Purpose
This project demonstrates my understanding of Java and object-oriented software design, including how inheritance and interfaces can be used to represent different animal types and behaviours.
